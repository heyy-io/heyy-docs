## All triggers

Browse triggers by category in the sidebar, or jump to a specific trigger below.

| Trigger | When it runs |
| ------- | ------------- |
| [New incoming chat](/help/automations/triggers/new-incoming-chat) | First message creates a new chat |
| [Reopened chat](/help/automations/triggers/reopened-chat) | Message in a previously closed chat |
| [New & reopened chat](/help/automations/triggers/new-and-reopened-chat) | Any time a chat opens (new or reopened) |
| [New incoming message](/help/automations/triggers/new-incoming-message) | Every new message in an existing chat |
| [Chat closed](/help/automations/triggers/chat-closed) | Chat is closed |
| [Chat assigned](/help/automations/triggers/chat-assigned) | Chat assigned to selected users |
| [Chat moved](/help/automations/triggers/chat-moved) | Chat moved to selected inboxes |
| [New Instagram comment](/help/automations/triggers/new-instagram-comment) | Comment on Instagram content |
| [Contact created](/help/automations/triggers/contact-created) | New contact record |
| [Contact attribute updated](/help/automations/triggers/contact-attribute-updated) | Selected attributes change |
| [Label added](/help/automations/triggers/label-added) | Selected labels added |
| [Label removed](/help/automations/triggers/label-removed) | Selected labels removed |
| [Webhook received](/help/automations/triggers/webhook-received) | External webhook hits your endpoint |
| [Manual trigger](/help/automations/triggers/manual-trigger) | Started manually or from another flow |
