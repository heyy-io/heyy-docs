---
title: "Custom attributes (columns)"
description: "Show workspace attributes as columns on the Contacts table and edit values on the record."
---

**Attributes** are custom fields on the contact record (lead stage, plan, language, and so on). On the Contacts mini-CRM you can surface them as **table columns** and edit values without opening every profile.

## Add attribute columns to the table

1. Open [**Contacts**](https://app.heyy.io/contacts).
2. Open the column picker and add the **attributes** you want visible.
3. Reorder columns with [Column order & visible fields](/help/contacts/mini-crm/column-order-and-visible-fields).

Inline edits update the **contact**; automations, journeys, and [AI Employees](/help/ai-employees/capabilities/read-contact-fields) use the same fields when you expose them.

## Create or change attribute definitions

New attribute types and field settings are managed in [**Settings → Attributes**](https://app.heyy.io/settings/attributes)—not from the Contacts table alone.

Attributes also appear on the Inbox [contact card](/help/inbox/contact-card) and in [advanced filters](/help/contacts/search-and-filters/advanced-filters) when building segments.
