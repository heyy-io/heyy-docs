---
title: "Add an AI employee to an automation"
description: "Use the AI Employee action in the automation editor."
---

1. Open [**Automations**](https://app.heyy.io/automations) and edit a workflow.
2. Add an **AI Employee** action node.
3. Select the [channel](/help/ai-employees/going-live/channel-and-context) and employee.
4. Map [exit points](/help/ai-employees/going-live/use-exit-points-in-automations) and configure [timeouts](/help/ai-employees/going-live/reply-timeouts).
5. Publish the automation.

See [How AI employees work in automations](/help/ai-employees/going-live/how-ai-employees-work-in-automations) for the full mental model. See [AI actions](/help/automations/ai-actions) for how this action fits among other automation steps.
