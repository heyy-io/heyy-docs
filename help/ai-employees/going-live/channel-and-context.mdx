The **AI Employee** automation action has three fields that determine how the step runs.

| Field | What it controls |
| ----- | ------------------ |
| **Channel** | Which connected channel this step applies to — Live Chat, WhatsApp, Instagram, or Facebook Messenger. |
| **AI Employee** | Which configured, live employee runs in this step. |
| **Context** | Optional extra instructions that apply only inside this automation — see [Automation guideline overrides](/help/ai-employees/going-live/automation-guideline-overrides). |

<Frame>
  ![Channel and employee selection](/assets/ai-employees-automations-channel-context.png)
</Frame>

## Channel must match the trigger

The channel selected on the AI Employee action must match where the automation's trigger fires. A mismatched channel is the most common reason an employee never runs — the trigger fires, the automation executes, but the AI Employee step is configured for a different channel and silently does nothing.

<Tip>
  If an employee is not replying and everything else looks correctly configured, check this field first — it is a frequent, easy-to-miss misconfiguration.
</Tip>

Only a **live** employee appears in the picker — see [employee status](/help/ai-employees/going-live/how-ai-employees-work-in-automations#employee-status-active-inactive-retired) if the one you expect is missing.
