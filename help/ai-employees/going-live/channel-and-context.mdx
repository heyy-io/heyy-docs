---
title: "Choose channel and context for the step"
description: "Configure the AI Employee automation node."
---

In the **AI Employee** automation action:

- **Channel** — Which connected channel this step applies to.
- **AI Employee** — Which configured employee runs.
- **Context** — Extra instructions for this automation only (optional).

Channel must match where the trigger fires. Wrong channel selection is a common reason the employee never runs.
