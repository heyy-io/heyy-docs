---
title: "Create exit points"
description: "Define when the AI should hand off, close, or branch."
---

**Exit points** tell your employee when a conversation should stop and continue elsewhere in your automation — handoff to a human, close the chat, run a follow-up action, or branch to another path.

Each exit point has:

- **Name** — A label your team recognizes in the app and automation editor
- **Prompt** — Natural-language instructions for when this exit should fire
- **Status** — Active or inactive

## Create an exit point

On the **Exit points** tab:

1. Click **New exit point**.
2. Enter a **name** (for example, "Request human" or "Issue resolved").
3. Write the **prompt** — describe the situation that should trigger this exit.
4. Set **status** to active when you are ready to use it.
5. Save.

Write prompts the way you would brief a teammate: specific, observable situations work better than vague rules. Align handoff exits with [Boundaries](/help/ai-employees/identity-and-guidelines/boundaries).

Test each exit point in the [Playground](/help/ai-employees/going-live/test-in-playground). Wire exits in automations via [Use exit points in automations](/help/ai-employees/going-live/use-exit-points-in-automations).
