---
title: "Choose which attributes to expose"
description: "Pick built-in vs custom fields for context."
---

Built-in fields include first name, last name, email, and phone number. Custom fields come from [**Settings → Attributes**](/help/contacts/mini-crm/custom-attributes-as-columns).

On **Attributes**, for each field you can enable:

- **Read** — The employee can see the value during the conversation
- **Share** — The employee can tell the contact the value
- **Update** — The employee can write a new value to the contact

Expose the minimum set:

- **Support** — Name, issue-related custom fields
- **Sales** — Contact details, lead status attributes
- **General** — Brand-safe defaults only

See [read](/help/ai-employees/capabilities/read-contact-fields) and [update](/help/ai-employees/capabilities/update-contact-fields) for step-by-step setup.
