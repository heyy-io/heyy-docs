---
title: "Actions overview"
description: "Functions your employee can invoke during conversations."
---

On the **Actions** tab, define tools the employee may call actively during a chat — not just knowledge it retrieves passively.

Available action types:

| Action | Purpose |
| ------ | ------- |
| **Custom API** | Call an external HTTP endpoint with mapped inputs and responses |
| **Trigger automation** | Start another Heyy automation for this contact |

Contact field read, share, and update is configured on **Attributes**, not here. Expose only the attributes the employee needs, then reference them in [guidelines](/help/ai-employees/identity-and-guidelines/write-your-guidelines).

Add actions sparingly — each one is a decision the model can make mid-conversation. Test in the [Playground](/help/ai-employees/going-live/test-in-playground) after adding or editing actions.
