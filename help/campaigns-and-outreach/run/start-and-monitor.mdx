---
title: "Start & monitor a campaign"
description: "Launch a campaign and follow execution progress."
---

When your [audience](/help/campaigns-and-outreach/build/audience-and-recipients) and [message](/help/campaigns-and-outreach/build/message-and-templates) are ready, **start** the campaign from [**Campaigns**](https://app.heyy.io/campaigns).

## Launch

1. Review campaign settings and recipient count.
2. Start the send (or schedule, if your workspace supports it).
3. Open the **execution** for that run to monitor progress.

Each run has an execution view showing how the broadcast is progressing across contacts.

## While it runs

Watch high-level status on the execution page. As results come in, use [Delivery & failures](/help/campaigns-and-outreach/run/delivery-and-failures) to see who was reached and who was not.

You can start another campaign from the same area when you need a follow-up—useful after fixing template or channel issues.

## API

Programmatic sends use broadcast endpoints: `POST /{channelId}/broadcasts` and `POST /{channelId}/broadcasts/{broadcastId}/start`. See [API Reference](/api-reference/overview).
