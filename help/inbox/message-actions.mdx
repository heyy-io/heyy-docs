**Message actions** apply to one message inside a conversation, as distinct from [chat actions](/help/inbox/chat-actions), which apply to the conversation as a whole. Hover over a message in the thread to reveal the options available for it.

## Delivery status

Every outbound message carries a status so you know what happened to it without asking the contact:

| Status | Meaning |
| ------ | ------- |
| **Sent** | Left Heyy and was handed to the channel. |
| **Delivered** | Reached the contact's device. |
| **Read** | The contact opened it (where the channel reports read receipts). |
| **Failed** | The channel rejected or could not deliver it. |

## If a message shows as failed

1. **Check the conversation window first.** The most common cause on WhatsApp, Messenger, and Instagram is a message being sent as free-form text after the reply window already closed — see [Conversation window](/help/inbox/chat-fundamentals/conversation-window).
2. **Resend as a template** if the window has expired — see [Chat actions](/help/inbox/chat-actions) for **Send a WhatsApp template**.
3. **Retry the send** if the window is still open — a failure with the window open usually points to a temporary channel issue rather than a policy block.
4. **Check the channel's status page** if failures continue across multiple contacts — see [messaging channel troubleshooting](/help/messaging-channels/whatsapp/common-issues).

<Tip>
  Delivery status is the fastest first signal when a contact says "I never got your message." Check the status on your last sent message before assuming the issue is on the customer's end.
</Tip>

## Copying message text

Hover over a message and use the copy option to grab its text — useful for pulling a customer's exact wording into a [note](/help/inbox/contact-card#notes), a [quick reply](/help/inbox/use-quick-replies) you're building from a real example, or a ticket in another system.
